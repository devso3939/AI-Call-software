What's inside

Every feature is backed by a real backend effect — no fake buttons (master prompt §116).

📞

Free on-net browser calls

Register, dial another OpenCall user, talk over WebRTC through your own LiveKit SFU. Zero cost, zero vendor.

🤖

Human ↔ AI voice calls

Local AI agents (VAD → STT → LLM → TTS) answer calls in-browser. Runs against LM Studio/Ollama on your machine — by default LOCAL_AI=true.

🧭

Honest route classification

The dialer always shows what a destination is: FREE ON-NET, SIP, FEDERATED, PSTN — COST MAY APPLY, or NO ROUTE. Never hides the truth (§37).

🔗

Guest call links

Can't reach someone on-net? Create a short-lived link — the recipient joins from their browser with no account (§39).

📈

Live call quality

Mute/End controls, quality indicator and RTT measured from real RTP statistics — the same numbers you'd see in a network console.

📱

Real phone calls (PSTN)

Dial any number worldwide via Twilio Voice — it rings their mobile/cellular network. Access tokens are minted inside the database, so credentials never touch the browser. Requires your own Twilio account & number.

Run your own — 3 commands (Windows)

One script checks prerequisites, downloads LiveKit, migrates the DB and starts everything.

git clone https://github.com/devso3939/AI-Call-software.git
cd AI-Call-software
./start-dev.ps1

Then open http://localhost:3000 in two browser profiles, register two users, and call each other.
