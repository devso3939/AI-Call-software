📲 Better: install the web app (nothing to unblock)

1

Open the web app in Chrome on Android.

2

Tap the 📲 Install OpenCall app button (bottom-right) — or Chrome menu ⋮ → Add to Home screen.

3

It installs like a native app — own icon, full-screen window, works offline — with zero Play Protect involvement.

Recommended pairing: install the PWA on your daily phone (make/receive calls in browser) + the APK gateway on a spare phone (free SIM calls/SMS). Both pair with the same account in Devices.

🔑 After install: pair in 60 seconds

1

Open the web app → Devices → Pair Android device → copy the 6-digit code (valid 15 min).

2

Open the Gateway app → paste code → Pair → grant the permissions it asks for (calls, SMS, microphone).

3

Tap Start gateway. The status pill turns green in the web app — you're live.
