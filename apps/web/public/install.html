🟢 What's new in v1.5.1 — Bridge now actually works

v1.5.0's Bridge paired fine but had a bug: it never picked up commands from the server, so calls stayed "created" and SMS stayed "queued". v1.5.1 fixes it with a tap-to-dial / tap-to-send design that keeps Bridge 100% permission-free:

📞 Calling via Bridge (v1.5.1): place a call in the web app → a heads-up notification appears on your phone: "Tap to dial +995…" → tap it, the dialer opens pre-filled, press call → the moment the person answers, audio is bridged into your browser. The web app shows "Waiting for you to dial via your Android…" until you tap (90 s to tap, otherwise the call expires).

💬 SMS via Bridge (v1.5.1): send an SMS in the web app → a notification appears: "Tap to send SMS" → tap it, your messaging app opens pre-filled with the recipient + text → press send. The message shows "tap the notification on your phone to send" in the web app until you do.

One more thing to set once: open the Bridge app → enter your own SIM number (e.g. +995598…) → Save SIM number. This makes the web app show your real number instead of "not set" and marks you as a caller.

🚨 Your exact message — decoded (v1.5.0)

“This app can request access to sensitive data. This can increase the risk of identity theft or financial fraud.” is Google's financial-fraud prevention: it blocks unverified apps that request SMS or Phone permissions. It reads the app's permission declarations + developer registration — not the code. That's why rebuilding or re-signing never removed it, and why registered apps install silently.

So v1.5.0 ships two apps:

🟢 OpenCall Bridge (app.opencall.bridge) — internet calling with your microphone. Zero SMS/Phone permissions → installs with NO warning. Use this to call from the web app through your phone's mic & speaker.

🟡 OpenCall Gateway (app.opencall.gateway2) — full SIM power: SMS relay in/out, dial/answer cellular calls. The warning still appears for this one until you register the app — see the permanent fix below.

* "May show a warning" = Google's one-tap More details → Install anyway dialog — not a malware verdict. Register the app (section below) and it disappears forever.

🚀 Install in 4 steps

1

Download the APK on your Android 8.0+ phone (links above — pick Bridge for zero warnings, Gateway for full SIM features).

2

Open it. If the sensitive-data dialog appears on Gateway: tap More details → Install anyway (or register first, per the section above). Bridge never shows it.

3

In the web app open the Devices tab → Create pairing code → type the 6 digits into the app → Pair.

4

Tap Start gateway (Gateway) or Start bridge (Bridge). The status screen shows the exact version + package name — useful for verification.

5

Bridge users: on the app's main screen enter your SIM number and tap Save SIM number — the web app then shows it under your device in the Devices tab.

No APK at all? The web app installs as a PWA (Chrome → ⋮ → Install / “Add to Home screen”) with zero Play Protect involvement — full internet calling, no SIM relay.
