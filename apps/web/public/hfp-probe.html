Bluetooth HFP Probe

Checks whether this computer can capture your phone's cellular call audio digitally over Bluetooth Hands-Free Profile — the zero-cost path to browser-side call audio and two-way recording.

Before you start

  1. Pair your Android phone to this computer over Bluetooth.
  2. Windows: Settings → Bluetooth → the phone → make sure the phone's Bluetooth settings have Phone calls / Call audio enabled for this computer.
  3. Place or receive a real phone call on the phone, and set the phone's in-call audio output to this paired computer (the in-call screen usually offers it as a Bluetooth / audio-output choice).
  4. Keep the call connected, then run the steps below.
